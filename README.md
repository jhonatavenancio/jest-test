# Calculadora de Desconto

Projeto Node.js para praticar testes unitários com Jest.

## 🚀 Instalação

```bash
npm install
```

## ▶️ Rodar os testes

```bash
npm test
```

## 📁 Estrutura

```
├── src/
│   ├── calculadora.js       # Código principal
│   └── test/
│       └── calculadora.test.js  # Testes
```

## 🧪 O que tem no projeto

- **calcularDescontoPercentual** - Aplica desconto percentual
- **calcularDescontoProgressivo** - Desconto por quantidade
- **aplicarCupom** - Aplica cupons de desconto
- **verificarElegibilidade** - Verifica se produto tem desconto
- **calcularDescontoAcumulativo** - Combina descontos
